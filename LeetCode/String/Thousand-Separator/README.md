## Problem Statement

Given an integer `n`, add a dot (&quot;.&quot;) as the thousands separator and return it in string format.

&nbsp;

Example 1:**

```

**Input:** n = 987
**Output:** &quot;987&quot;

```

Example 2:**

```

**Input:** n = 1234
**Output:** &quot;1.234&quot;

```

&nbsp;

**Constraints:**

	- `0 &lt;= n &lt;= 231 - 1`
